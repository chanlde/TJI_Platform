- productId：`7`

## 产品定位

破窗弹是四通道载荷控制产品。App 展示设备在线状态、安全锁、当前通道、激光状态和击发状态，并通过 MQTT 完成查询、解锁、上锁、通道选择、激光开关和击发控制。

## 当前业务边界

- 一个设备包含 1～4 号四个通道。
- 设备在线且解锁后才能选择通道。
- 设备在线、已解锁且已选择合法通道后才能击发。
- 击发使用滑动确认，避免普通点击误触。
- 当前不提供悬浮窗快捷控制。
