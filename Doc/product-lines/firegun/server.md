## 账号与设备

当前兼容登录继续查询消防吊桶产品 ID `2` 的账号绑定。App 根据 `HydroGunLink_` 名称前缀将对应 Link 展示为 FireGun；因此后台设备名称、Link SN 和下方 ESP32 SN 的录入及返回字段都需要在真实账号上核对。一个账号可以绑定多台设备，一台设备也可以关联多个账号。

## 固件与日志

新后台的固件当前发布包按产品与硬件版本选择。当前不能因为喷枪沿用登录 productId `2`，就自动选择消防吊桶固件；喷枪的独立固件键、设备版本上报及真实升级协议须先明确。设备控制业务回执和 OTA 完成证明也不能互相替代。
