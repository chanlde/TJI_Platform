## 产品定位与当前边界

消防喷枪已作为 TJI Platform 中的独立控制模块。当前服务器仍按消防吊桶产品 ID `2` 绑定 Link；App 通过设备名称前缀 `HydroGunLink_` 区分喷枪与普通吊桶。Link 序列号用于 MQTT Topic，下方 ESP32 序列号用于控制载荷和回执归属。

App 已实现解锁、展开、收回、停止、Link 心跳与下方设备状态展示，主控制页和悬浮窗共用运行时状态。现有证据是源码、单测和本地构建；真实喷枪动作、设备安全边界与公网链路尚未完成本次验收。

## 升级与交付

当前没有证明喷枪已使用独立固件发布键或完成 4G OTA。沿用产品 ID `2` 不等于可以把消防吊桶固件下发给喷枪；固件适配必须在设备硬件和服务端发布规则确认后再开放。
